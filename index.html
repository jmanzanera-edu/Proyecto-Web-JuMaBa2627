Trabajando con Git y GitHub

¿Qué es Git?

Git es un sistema de control de versiones distribuido que funciona de manera local en tu ordenador. Permite registrar cada cambio que realizas en el código de un proyecto, volver a versiones anteriores si algo falla y trabajar en distintas ramas sin afectar la versión principal.

GitHub y el trabajo en la nube

GitHub es una plataforma en la nube diseñada para alojar repositorios creados con Git. Facilita la colaboración entre desarrolladores mediante herramientas como las Pull Requests (solicitudes de cambios), el seguimiento de errores (Issues) y la revisión de código en equipo.

Comandos básicos esenciales

Para empezar a gestionar un proyecto desde la terminal, estos son los comandos fundamentales:

  • git init: Crea un nuevo repositorio local en la carpeta actual.
  • git add .: Prepara todos los archivos modificados para ser guardados.
  • git commit -m "mensaje": Guarda una instantánea de los cambios con una descripción.
  • git push: Sube tus confirmaciones locales al repositorio remoto en GitHub.
