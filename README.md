# Actividad 3.1 Trabajando con Git y Github

Este repositorio contiene los archivos y prácticas realizadas para la **Actividad 3.1**, cuyo objetivo es aprender y aplicar los comandos básicos de control de versiones con **Git** y la gestión de repositorios remotos en **GitHub**.

## Objetivos
* Inicializar un repositorio local y gestionar el historial de cambios mediante commits.
* Conectar un repositorio local con un repositorio remoto en GitHub.
* Practicar el flujo de trabajo básico (`add`, `commit`, `push`, `pull`).
